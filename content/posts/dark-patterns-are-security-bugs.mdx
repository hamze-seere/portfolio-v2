---
title: Dark patterns are security bugs
publishedAt: 2025-11-30
summary: If an interface tricks the user, an attacker can borrow the trick.
track: web
---

If your interface can trick a user into clicking "Allow", so can a phishing page that copies it.

Dark patterns train people to stop reading. A confirm-shaming dialog today is a consent-phishing prompt tomorrow, and your users have already learned to click through.

Clear, boring, honest interfaces are a security control. Treat manipulative UI as a vulnerability and file it like one — with a severity, an owner and a fix date.
